# Vendored KiCad libraries

`Seeed_Studio_XIAO_Series.kicad_sym` and `Seeed_Studio_XIAO_Series.pretty/` (symbol and footprints of the
Seeed Studio XIAO modules) come from Seeed Studio's
[OPL_Kicad_Library](https://github.com/Seeed-Studio/OPL_Kicad_Library) (folder "Seeed Studio XIAO Series
Library"), which is published under **CC BY-SA 4.0**. The files here may have been adapted for this
project (KiCad 10 format). They stay under CC BY-SA 4.0, like the rest of this repository.
